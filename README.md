# Budget

**Abendbudget** – kleine Web-App für Geschäftsreisen: Budget fürs Abendessen und Reisezeitraum festlegen, Ausgaben eintragen, Restbudget pro Abend und das voraussichtliche „Aufgebraucht am“-Datum sehen. Für Geschäftsessen erzeugt sie einen Bewirtungsbeleg als PDF.

App: https://elitepole92.github.io/Budget/

- Als Webseite (GitHub Pages) werden die Daten nur im jeweiligen Browser gespeichert.
- Der Rechnungs-Scan (Auslesen per Claude) und das Speichern im Claude-Konto funktionieren nur, wenn die App als Claude-Artefakt geöffnet wird.
- Alles steckt in einer Datei: `index.html`.
